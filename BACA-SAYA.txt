KAWAN BELAJAR
Game belajar untuk anak usia 2 sampai 12 tahun (KB, TK A, TK B, SD 1-2, SD 3-4, SD 5-6)
Karakter: Awan (kucing awan), Bintang (kelinci bintang), Bulan (beruang bulan). Semuanya karakter orisinal.

ISI GAME
- 7 pelajaran: Membaca, Menulis, Logika, Matematika, Bahasa Inggris, Hitung Cepat, Sempoa
- Isi menyesuaikan jenjang. KB dan TK A punya 5 pelajaran (belum ada Hitung Cepat dan Sempoa).
  TK B sampai SD 5-6 punya semua 7 pelajaran. Sempoa di TK B hanya perkenalan 1 batang.
- Tingkat kesulitan naik atau turun sendiri mengikuti jawaban anak (3 tingkat per jenjang).
- Soal yang salah akan diulang di sesi yang sama dan di sesi berikutnya.
- Hadiah bintang, lencana, dan hari beruntun. Progres tersimpan di perangkat.
- Tidak ada hukuman: jawaban salah diberi kesempatan kedua, lalu jawabannya ditunjukkan dengan lembut.

CARA MAIN
Buka file index.html di Chrome, Edge, atau Safari. Game langsung jalan.
Selama rekaman belum dibuat, game memakai suara sistem perangkat (suara bawaan Windows/Chrome/Edge, tanpa internet).
Awan, Bintang, dan Bulan dibedakan lewat nada, tempo, dan suara pria/wanita jika perangkat punya keduanya.
Suara sistem tiap perangkat berbeda-beda, jadi hasilnya bisa terdengar kurang natural. Untuk suara yang lebih baik, lihat bagian berikut.
Tips: di Edge, suara bahasa Indonesia "Natural" (Gadis dan Ardi) biasanya jauh lebih bagus daripada di Chrome.

AGAR TIAP KARAKTER PUNYA SUARA SENDIRI (SATU KALI SAJA)
Rekaman di folder "audio" selalu diutamakan. Jika sebuah rekaman ada, itu yang diputar; jika tidak, game memakai suara sistem.
Awan, Bintang, dan Bulan masing-masing punya folder suara sendiri: audio/awan, audio/bintang, audio/bulan.
Rekaman dibuat sekali dengan VoiceStudio yang berjalan di komputer Anda (suara bisa dirancang dari deskripsi teks).
Langkah lengkapnya ada di  tools/SUARA.md. Ringkasnya:
  1. Pasang VoiceStudio dari https://github.com/debpalash/VoiceStudio/releases dan rancang tiga suara.
  2. Pasang Python, lalu jalankan:  python tools/buat_suara.py --cek
  3. Isi nama suara tiap karakter di tools/suara.json.
  4. Coba dulu:  python tools/buat_suara.py --batas 10    lalu buat semuanya:  python tools/buat_suara.py
Cadangan tanpa VoiceStudio: python tools/buat_suara.py --mesin edge  (suara Microsoft, butuh internet).
Jika ada yang gagal, jalankan lagi. Yang sudah jadi akan dilewati.
Anda juga boleh merekam suara sendiri atau suara orang tua: ganti file mp3 di folder "audio/<karakter>"
dengan nama file yang sama (daftar kalimat dan nama filenya ada di tools/manifest.json).

BERMAIN DI TABLET ATAU HP
Cara paling mudah: di komputer, buka terminal di folder ini lalu jalankan
    python -m http.server 8000
Di tablet (satu Wi-Fi), buka  http://ALAMAT-IP-KOMPUTER:8000  lalu pilih "Tambahkan ke layar utama".
Atau unggah seluruh folder ini ke layanan hosting statis milik Anda sendiri (hanya untuk keluarga).

MENAMBAH ATAU MENGUBAH SOAL
- Bank kalimat dan bacaan: js/content.js
- Pembuat soal per jenjang dan pelajaran: js/gen.js (bagian GENS di bagian bawah)
- Setelah mengubah teks yang diucapkan, jalankan:  node tools/check.js --manifest
  lalu jalankan lagi  python tools/buat_suara.py  untuk membuat rekaman kalimat yang baru.
- Pemeriksa otomatis: node tools/check.js  (memeriksa puluhan ribu soal acak)
